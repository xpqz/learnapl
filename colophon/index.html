Colophon

Once men turned their thinking over to machines in the hope that this would set them free. But that only permitted other men with machines to enslave them. --Frank Herbert Herbert, 1965

This is the second edition of Learning APL, revised for Dyalog APL 21.0.

The book is written as a collection of Jupyter notebooks and built into a website with Jupyter Book, which is powered by the MyST document engine. Every APL expression in the book was executed live against Dyalog APL 21.0 through the Dyalog Jupyter kernel, so the results you see are real interpreter output rather than hand-typed.

APL code is set in APL387 Unicode, a redrawn and extended version of Adrian Smith’s classic APL385 Unicode typeface.

The source lives at github.com/xpqz/learnapl; corrections and suggestions are welcome as issues there.

Notes¶

This book started as a very personal project which grew out of obsessive note taking during my own “learning APL” process. My APL knowledge at the time I started writing was nothing worth shouting about; I was very much learning on the job, so to speak. I rewrote large chunks several times as my knowledge improved, but looking at edition 1 today, several chapters are embarrassingly weak. Edition 1 started on the tail end of Dyalog v17, lived through the exciting times of the v18.0-18.2 releases to finally land on early v19 betas. Dyalog’s now at v21, and a lot of things have changed, notably the introduction of Array Notation (APLAN) which came out in v20. The second edition unapologetically makes full use of all the latest features. It’s an introduction to modern APL, after all.

My own situation has changed, too -- I wrote the first edition whilst working at IBM, and now I’m working for Dyalog. A case of poacher turned game-keeper, perhaps? Whilst I am now a Dyalog employee, this book isn’t a “Dyalog product”, it’s very much still my personal labour of love. It’s been very gratifying that so many readers have reached out to let me know that this book set them on the path of APL. I hope you’ll like the second edition, too.
